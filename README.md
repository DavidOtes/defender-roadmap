# Defender Roadmap

A 12-month Blue Team + GRC study plan with a full CompTIA Security+ SY0-701 companion, progress tracking and accountability. Static site, no build step, no backend.

## Structure

- `index.html`, `css/style.css`, `js/app.js` — the app (hash-routed single page)
- `data/roadmap.json` — the five phases, 30 tasks with why/how/resources/done-when, certs, outlook
- `data/secplus/d1.json` … `d5.json` — one file per Security+ domain: every Professor Messer video with a deep dive, key terms, exam tips, on-the-job note and a 3-question self-check
- `data/secplus/index.json` — manifest, generated by `node scripts/build-index.js`
- `scripts/build-index.js` — merges split domain files, validates content, writes the manifest

## Run locally

```
python3 -m http.server 8123
# open http://localhost:8123/
```

The app fetches JSON, so it must be served over HTTP (not opened from disk).

## Deploy

```
vercel --prod
```

## Progress data

Everything the learner records (ticks, video status, confidence, notes, quiz scores, study sessions, practice exam scores, weekly check-ins, settings) lives in `localStorage` under `defender-roadmap-v2`. Settings has export/import for backups.
